# Dr Vocal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un assistant vocal Windows local, réveillé par « salut docteur », qui pilote Spotify, Discord, les notes et Claude Code sans sortir l'utilisateur de son jeu.

**Architecture:** Un seul processus Python. Une boucle audio légère (réveil → fin de phrase → transcription) alimente un analyseur de règles qui produit une `Intent`. Seules les actions d'un catalogue fermé sont exécutables. Claude Code tourne à part, dans une session pilotée dont une politique filtre chaque outil.

**Tech Stack:** Python 3.12 (uv), sounddevice, openWakeWord, silero-vad, faster-whisper, piper-tts, spotipy, discord.py, claude-agent-sdk, pywebview, pytest.

**Spec:** `docs/superpowers/specs/2026-11-02-dr-vocal-design.md`

## Global Constraints

- Windows 11, usage personnel, un seul utilisateur.
- Aucun audio ne sort du PC, et rien n'est transcrit, avant le mot de réveil.
- Aucune action de suppression de fichier ou de fermeture d'application dans le catalogue.
- Aucun selfbot Discord, sous aucune forme.
- Aucune clé API Claude : `ANTHROPIC_API_KEY` est retirée de l'environnement de la session Claude.
- Aucune touche n'est jamais simulée vers un jeu ; aucune fenêtre ne prend le focus.
- Pas de voix par défaut, seulement des sons. La voix sert à relire un message Discord et aux questions de Claude.
- Une autorisation ne s'accepte que par « oui docteur ». Sans réponse comprise, rien n'est exécuté.
- Secrets dans `secrets.toml`, ignoré par git. Réglages dans `config.toml`.
- Cibles : veille < 2 % du processeur total et < 300 Mo de RAM ; < 1 s de la fin de phrase à l'action courante ; < 1 faux réveil par heure de discussion.
- Travail sur une branche `feat/dr-vocal`, jamais sur `main`.

## Review Focus

1. Transcription vide ou réduite à du bruit après le réveil : son d'échec, aucune action (Task 2).
2. Spotify sans appareil actif : son d'échec, pas de plantage (Task 6).
3. Nom Discord ambigu, ou utilisateur absent des salons vocaux : aucune action (Task 8).
4. Limite d'abonnement Claude atteinte en cours de session : session marquée en erreur sur le deuxième écran, le reste de l'assistant continue (Task 9).
5. Micro débranché pendant une partie : reprise automatique, sans plantage (Task 3).
